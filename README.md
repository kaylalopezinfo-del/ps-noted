# P.S. Noted — psnoted.com

> Save the good stuff from every AI conversation.

This is the landing page and site for **P.S. Noted** — a Chrome extension that lets you highlight responses, save prompts, and organize everything into profiles and boxes across Claude, ChatGPT, Gemini, and any AI tool.

## Pages

- **[index.html](index.html)** — Landing page
- **[privacy.html](privacy.html)** — Privacy policy
- **[share.html](share.html)** — Shared collection preview page

- Hosted on GitHub Pages
